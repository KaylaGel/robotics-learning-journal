# Learning resources

Official sources reviewed 15 October 2026. Use documentation matching your installed version; links to moving documentation are not dependency pins.

| --- | --- | --- |
| [Python tutorial](https://docs.python.org/3/tutorial/) | Language fundamentals | Phase 0–1 |

## Source hygiene

Save access date and software commit in experiment records. Prefer official instructions over copied commands from old videos. Keep notes in your own words; link to upstream media and code rather than copying it without checking its licence.
