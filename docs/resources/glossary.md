# Robotics glossary

| Term | Meaning |
| --- | --- |
| Actuator | Component that turns a command into physical motion or force |
| Observation | Sensor/state information available to a controller or policy |
| Action | A command, whose units and representation depend on the interface |
| Policy | A rule or learned model mapping observations to actions |
| Joint space | Representation using joint variables such as angles |
| Task space | Representation of an end effector or object in a workspace |
| Coordinate frame | A reference origin and axes for expressing geometry |
| Forward kinematics | Mapping joint configuration to end-effector pose |
| Inverse kinematics | Finding joint configurations for a desired pose |
| Feedback | Using measured behaviour to adjust commands |
| Teleoperation | Human operation through a remote input interface |
| Episode | One recorded task attempt or interaction sequence |
| Imitation learning | Learning behaviour from demonstrations |
| Reinforcement learning | Learning behaviour through reward-guided interaction |
| VLA | Vision-language-action model |
| Distribution shift | Conditions differ from those represented during training |
| Sim-to-real gap | Differences between simulation and physical behaviour |
| Calibration | Establishing mappings/reference values needed for consistent measurements or motion |
| Latency | Time between an event, observation, or command and its downstream effect |
| ROS 2 | Middleware and tools for building robot software |
| LeRobot | Hugging Face's robotics learning software ecosystem |
| SO-101 | An arm platform used in the flagship project |
